One brutally honest software error line for make.fun's "Say What Actually Broke" bounty: a single line of error copy, at most 200 characters, that names the real failure and makes the user laugh. `main.py` (pure Python stdlib, deterministic, no network) writes the line to `/output/entry.txt`.

## The line

> Upload failed: the file was fine, you were fine — our server ran out of disk because someone's been storing cat videos in /tmp since 2021. Try again in 10 minutes.

## Run it

```sh
python3 main.py
```

See `CANDIDATES.md` for the shortlist the line was picked from.
